## 2. r/ClaudeAI

**Title:** I built a policy engine that blocks Claude Code/Cursor agents from committing secrets — looking for feedback

**Body:**

Every AI coding agent I've used will eventually try something you don't want — commit a `.env`, run `rm -rf`, hallucinate a deprecated API, or burn your API budget in a loop.

I got tired of guardrails that are just *suggestions* in a system prompt, so I built **aiZee**: a local control plane that sits between you and the agent and enforces policy on the actual action path.

How it works:

- One kernel pipeline gates everything: `Probity → Guardian → Policy → LoopDetector → Budget → Audit`
- Verdicts aren't just allow/deny/ask — policies can **rewrite** a payload (`modify`, audited) or **log-only** (`observe`)
- Prompt-injection detection on inbound content (regex + embeddings + optional LLM judge)
- Secret-leak checks on outbound responses
- Per-PR spend budgets on top of session/hour/day windows
- Tamper-evident audit log (SHA-256 hash chain + Ed25519 signatures)

On top of that it ships a full agent "OS": 245 skills, 29 auto-detected personas (works in Arabic too), BMAD-METHOD lifecycle vendored in, hybrid SQLite+vector memory, an MCP server with 46 tools, and a dashboard.

`pip install aizee && aizee bootstrap --target ~/.aizee` — the bootstrap materializes the whole skill/workflow/policy tree from the wheel.

7,685 tests, strict typing, all gates green. MIT.

Repo: https://github.com/m3taz-ahmed/aizee — the README has a demo GIF of the guardian denying a secret commit.

Questions I'd love input on: is per-action policy evaluation fast enough for your workflows? What verdict types are we missing?

## 3. r/cursor

**Title:** aiZee — governance layer for Cursor/Claude Code/Copilot agents (policy, budget, audit on the action path)

**Body:**

Cursor (and every other agent) is only as safe as its guardrails. Most "guardrails" today are prompt suggestions. aiZee enforces them in code.

What it does for your Cursor workflow:

- Blocks destructive commands and secret commits *before* they execute (`aizee check 'Bash' --args '{...}'` → deny)
- Detects prompt injection in tool output and file content (3 layers)
- Enforces token/cost budgets per session and per PR
- Auto-detects the right persona + skills for each task (29 personas, 245 skills, EN+AR)
- Keeps a tamper-evident audit trail of every agent action

It integrates via MCP — Cursor/Claude Code/any MCP client can route tool calls through aiZee's firewall + gateway. Also ships a skill library + BMAD agile lifecycle + hybrid memory, so it's a full agent OS, not just a linter.

Quick start: `pip install aizee && aizee bootstrap --target ~/.aizee && aizee doctor`

Repo + demo GIF: https://github.com/m3taz-ahmed/aizee

Happy to answer questions about the policy engine or the MCP integration.
