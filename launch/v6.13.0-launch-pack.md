**Body:**

Every AI coding agent I've used will eventually try something you don't want — commit a `.env`, run `rm -rf`, hallucinate a deprecated API, or burn your API budget in a loop.

I got tired of guardrails that are just *suggestions* in a system prompt, so I built **aiZee**: a local control plane that sits between you and the agent and enforces policy on the actual action path.

How it works:

- One kernel pipeline gates everything: `Probity → Guardian → Policy → LoopDetector → Budget → Audit`

- Secret-leak checks on outbound responses
- Per-PR spend budgets on top of session/hour/day windows
- Tamper-evident audit log (SHA-256 hash chain + Ed25519 signatures)

On top of that it ships a full agent "OS": ~250 skills, 29 auto-detected personas (works in Arabic too), BMAD-METHOD lifecycle vendored in, hybrid SQLite+vector memory, an MCP server with 53 tools, and a dashboard.

~8,000 tests, strict typing, all gates green. MIT. It's on PyPI and the Official MCP Registry.

## 4. r/AI_Agents (build-log format — not an ad)

**Title:** I spent months making an agent that can't commit my .env — here's the policy model that works

**Body:**

The problem everyone hits: your agent eventually runs a command you didn't want. Every guardrail I tried was a suggestion in a system prompt — the model can ignore it.

What worked: moving enforcement off the prompt and onto the action path. One pipeline gates every tool call:

`Probity → Guardian → Policy → LoopDetector → Budget → Audit`

Design decisions that mattered:

- **Verdicts beyond allow/deny/ask** — `modify` (rewrite the payload, audited) and `observe` (log-only). Most "bad" agent actions are 80% fine — rewriting beats blocking.
- **Injection defense needs layers** — regex patterns (13 techniques), embedding similarity, optional LLM judge. Any single layer is bypassable.
- **Budgets belong in the policy path** — not just session caps: per-hour, per-day, per-PR spend windows, enforced before the call runs.
- **Audit must be tamper-evident** — SHA-256 hash chain + Ed25519 signatures, or the log is just vibes.

Also built the OS around it: auto-detected personas (29, works in Arabic), ~250 skills, BMAD lifecycle, hybrid memory, MCP server (53 tools).

Open source, MIT: https://github.com/m3taz-ahmed/aizee — `pip install aizee`

What verdict types am I missing? How do you handle per-PR budgets?

## 5. r/mcp (technical)

**Title:** An MCP server that governs other MCP servers — tool-surface freeze, injection defense, per-call policy

**Body:**

aiZee's MCP server (53 tools) does two jobs: it exposes the governance kernel to any MCP client, and it *polices* other MCP servers:

- `aizee mcp freeze <server> [--check]` — snapshot-locks a server's tool definitions (name + description + inputSchema); detects rug-pulls when tools change under you
- `aizee security mcp` — audits MCP configs: secrets in args, unpinned packages, writable paths, WSL-absolute commands on Windows
- Fail-closed enforcement: if the kernel is unavailable and `AIZEE_ENFORCE_STRICT=1`, calls deny — never silently allow

`pip install aizee` → `"mcpServers": {"aizee": {"command": "aizee-mcp"}}`

On the Official MCP Registry: `io.github.m3taz-ahmed/aizee`. Repo: https://github.com/m3taz-ahmed/aizee
