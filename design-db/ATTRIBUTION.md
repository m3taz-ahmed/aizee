# Attribution

The CSV datasets in this directory are vendored from
[`nextlevelbuilder/ui-ux-pro-max-skill`](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
(`.claude/skills/ui-ux-pro-max/data/`), licensed **MIT** (c) Next Level Builder.

Contents: UI styles, product palettes + reasoning profiles, font pairings,
Google Fonts catalog, curated icons, UX guidelines, chart types, landing-page
patterns, GSAP motion presets, stack-specific guidelines (`stacks/`), plus the
upstream `catalog-summary.json` (sha256 snapshots) and `data-provenance.json`.

Upstream may refresh these datasets; `catalog-summary.json.verifiedAt` records
the vendored snapshot date. Re-vendor by re-copying the `data/` directory from a
fresh clone of the upstream repo.
