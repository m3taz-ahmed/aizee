# KDP walkthrough (field by field)

Drive the browser; hand the user the irreversible bits. Each format is a separate title:
Bookshelf -> "+ Create new title" -> Kindle eBook / Paperback / Hardcover.

## Things only the user can do
- Sign in / re-auth (KDP times out often). You NEVER type passwords.
- Native OS file pickers (manuscript + cover upload). Stage files in Downloads with obvious
  names first, then hand off the picker. You cannot drive an OS file dialog.
- Anything permanent and the final **Publish** click.
- Account gate: **2SV + tax/banking** must be complete before publish/payments.

## Kindle eBook
**Details:** Language English; Title + Subtitle (NO changes after publish); Author First/Last;
Contributors blank; Description (use the box's "Source" mode to paste clean <p> HTML);
Publishing rights = own copyright; Sexually explicit = No; Reading age blank for adult;
Categories (Choose categories -> up to 3); Keywords (7); Pre-order (release now, or pick a date).
**Content:** "Yes I have a file" -> Upload manuscript (the EPUB; user picks it). DRM = user's
permanent choice. Cover -> "Upload a cover you already have" -> the ~1600x2560 JPG (the front
cover downloaded from Cover Creator, or your front-cover art). Online Preview runs a quality
check; aim for "no spelling errors or image issues". ISBN optional (free ASIN). Publisher
optional. AI-Generated Content question is mandatory (see template). Accessibility: if your one
informative image has alt text, answer accurately.
**Pricing:** marketplace Amazon.com; royalty 70% (for $2.99-$9.99) or 35%; set USD price
(others auto-convert); KDP Select enroll or not; worldwide. Then user clicks Publish.

## Paperback / Hardcover (print)
**Print options:** trim 6x9 (common); interior ink - **THIS IS THE PRICING TRAP**:
"Premium color" charges color rates on EVERY page, so a near-all-text book is forced to a high
minimum price (a 174-page premium-color hardcover floored around $49.99). Use **Black & white**
interior for text books (a lone diagram prints grayscale, still legible) to get a cheap print
cost and a normal price (~$16.99-$18.99 paperback). Paper white/cream; finish matte/glossy;
bleed = "No Bleed" for a text interior.
**Manuscript:** upload the **manuscript DOCX** — KDP paginates it for the trim you chose. Do not
hand-build a 6x9 interior PDF; let KDP do the pagination (its page count is what Cover Creator
uses to size the spine).
**Cover:** use **Cover Creator** — drop in the Nano Banana front-cover art, let it lay in the
title/author and **auto-size the spine** to the page count, and paste the back-cover blocks.
Leave room for KDP's barcode (uncheck "my cover has a barcode"). No custom print-cover PDF.
**Pricing:** royalty is 60% of list minus print cost. Check the royalty figure KDP shows; if
it's a dollar or two, the interior-ink choice is the cause.

## Sanity checks before Publish
- Title/subtitle spelled exactly right (locked after publish).
- Cover is the intended one; manuscript passed the quality check.
- AI-content + DRM answered; pricing/royalty looks healthy.
- Pre-order date set if us
