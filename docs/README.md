# aiZee — Documentation Map

## Architecture & Contracts

| File | Purpose |
|------|---------|
| `BOOTLOADER.md` | The global bootloader — boot sequence, gate pipeline, what agents read at session start. |
| `INSTALL_CONTRACT.md` | `aizee.install.v1` — machine-readable boundaries for install/update/uninstall. Read before running installer scripts. |
| `skill-contract-template.md` | Optional `CONTRACT.md` template for directory skills — requires/produces/never-do, lintable via `aizee skill lint`. |

## Operations

| File | Purpose |
|------|---------|
| `DEPLOYMENT.md` | Production deployment, env config, health checks, rollback. |
| `ONBOARDING_SRE.md` | SRE quick-start: architecture overview + operating model. |
| `OPERATIONS.md` | Runbook: incident response, troubleshooting, emergency procedures. |

## Subdirectories

| Dir | Contents |
|-----|----------|
| `prompts/` | Reusable periodic master prompts (maintenance, research, review, audit) — see `prompts/README.md`. |
| `studies/` | Dated repo/ecosystem study reports — the knowledge base behind adopted patterns. |
| `audit/` | Deep-audit deliverables (report, capability map, gap analysis). Local-only — gitignored, regenerated by `prompts/deep-audit-prompt.md`. |
| `legal/` | AI disclaimer, privacy policy, terms of use. |
| `archive/` | Historical docs kept for reference (e.g. `features-v4.22.md` — superseded by `CHANGELOG.md`). |
| `media/` | README assets (demo.gif, social-preview.png) — referenced by raw.githubusercontent URLs. |
| `repos/` | Local-only images — gitignored, not shipped. |

## Notes

- Root-level docs stay at root by convention: `AGENTS.md` (bootloader),
  `spec.md`, `Memory.md`, `CHANGELOG.md`, `DESIGN.md`, `SKILL.md`,
  `AGENT_INSTALL.md`, `ACTIVE_CONTEXT.md` (live handoff file read by
  `aizee_mcp` context tools).
- New study reports go to `docs/studies/` named
  `study-<topic>-YYYY-MM-DD.md`; new periodic prompts go to `docs/prompts/`
  named `<purpose>-prompt.md` + a row in `prompts/README.md`.
- Moved/deleted tracked files must be registered in
  `scripts/stale_files.txt` so installed copies clean up on update.
